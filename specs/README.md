| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| [`003-genproj-docker-container`](003-genproj-docker-container/spec.md)                               | The `docker-container` capability and its contract.                                                                                                                                                                                                                                                                                                                                                                                                   |
| [`006-genproj-buildkite`](006-genproj-buildkite/spec.md)                                             | The `buildkite` capability and its contract.                                                                                                                                                                                                                                                                                                                                                                                                          |
| [`007-genproj-github-release`](007-genproj-github-release/spec.md)                                   | The `github-release` capability and its contract.                                                                                                                                                                                                                                                                                                                                                                                                     |
| [`008-genproj-container-agent`](008-genproj-container-agent/spec.md)                                 | The `container-agent` capability and its contract: every devcontainer's own registered agent.                                                                                                                                                                                                                                                                                                                                                         |
| [`009-genproj-micropython-lint`](009-genproj-micropython-lint/spec.md)                               | Defect record: `micropython` + `code-quality-python` firmware layout, the ruff target, and the README CI claim.                                                                                                                                                                                                                                                                                                                                       |
| [`010-genproj-micropython-board-chip`](010-genproj-micropython-board-chip/spec.md)                   | Defect record: the `micropython.board` product/chip conflation (new `chip` axis), and the CI-mention refinement.                                                                                                                                                                                                                                                                                                                                      |
| [`011-genproj-catalog-categories`](011-genproj-catalog-categories/spec.md)                           | The catalog owns the UI's sections: a top-level `categories` block, and the client that renders it instead of keeping its own list.                                                                                                                                                                                                                                                                                                                   |
| [`012-genproj-goose-requires-doppler`](012-genproj-goose-requires-doppler/spec.md)                   | Defect record: goose was installed and wrapped in every devcontainer, but only runs under the Doppler wrapper — one `hasGoose` gate for the binary, the shell wrapper, the config and the self-update.                                                                                                                                                                                                                                                |
| [`013-genproj-subrequest-free-tier`](013-genproj-subrequest-free-tier/spec.md)                       | Defect record: regeneration blew the Workers Free-tier 50-subrequest cap — GraphQL `createCommitOnBranch` replaces the per-file blob POSTs, one recursive tree fetch replaces the per-file content reads.                                                                                                                                                                                                                                             |
| [`014-genproj-docker-container-credentials`](014-genproj-docker-container-credentials/spec.md)       | Defect record: the Buildkite publish step resolved GHCR credentials only from Doppler while `docker-container` declared only `["docker"]`; fixed by a `hasDoppler` gate (fallback-only), not a hard dependency.                                                                                                                                                                                                                                       |
| [`015-genproj-docker-publish-idempotent`](015-genproj-docker-publish-idempotent/spec.md)             | Defect record: two builds of one commit raced the macOS keychain in `docker login`. A per-job `DOCKER_CONFIG` did not stop it (macOS uses `osxkeychain` even with no `credsStore`) and also hid `docker-buildx`; fixed by carrying the credential in `DOCKER_AUTH_CONFIG`, plus a skip for an already-published commit. Supersedes `016`.                                                                                                             |
| [`017-genproj-coding-agents-core`](017-genproj-coding-agents-core/spec.md)                           | Both agent capabilities (`coding-agents`, `container-agent`) become core and `locked` — always applied — and both resolvers seed them, so every generated project carries goose/Antigravity and its container agent (and, through `doppler`, Doppler). The now-empty `agents` category is removed. Supersedes their optionality from 008/011.                                                                                                         |
| [`018-genproj-docker-external-networks`](018-genproj-docker-external-networks/spec.md)               | `docker-container` gains an optional `externalNetworks` array so a generated container can join a pre-existing external Docker network (e.g. MCPHub's `ai_proxy`) by name. Empty is byte-identical; `networkMode: host` + non-empty is rejected as invalid config.                                                                                                                                                                                    |
| [`019-genproj-pydantic-agent-registration`](019-genproj-pydantic-agent-registration/spec.md)         | Defect record: the generated `pydantic-agent` trusted the owner-filtered `GET /v1/agents` listing, so a registered agent that the listing hid got a permanent duplicate-name refusal; ports a2a-goose's by-id fallback, remembered id, duplicate-name reclaim and honest failure. Flags that the capability has no spec of its own.                                                                                                                   |
| [`020-genproj-pydantic-agent-a2a-wire-honesty`](020-genproj-pydantic-agent-a2a-wire-honesty/spec.md) | Defect record: the generated `pydantic-agent` served FastA2A, whose card claims A2A `1.0` while its endpoint speaks `0.3`, so the gateway's `a2a-sdk` client sent `SendMessage` and every turn failed. Replaces FastA2A with the official `a2a-sdk` server pinned to the gateway client's version (`==1.1.0`), derives the advertised dialect from the accepted dialect, and adds a generated regression test (served card dialect == routed method). |

They were written while the generator lived inside the front-end repository and
moved here with the code. Read them as the reasoning behind the current shape,
not as a plan of work in progress: where a spec and the code disagree, the code
is what runs.

Specs 001 and 003 predate the split of the front-end out of this service, so
anything they say about the UI, sessions or sign-in describes the client, not
this repository.
